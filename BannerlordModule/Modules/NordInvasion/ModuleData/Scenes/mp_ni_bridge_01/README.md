# mp_ni_bridge_01

NI Bridge Fort - Chokepoint - Best for barricades

Сгенерировано tools/gen_ni_scenes.py. Entry points:
- 0-31: игроки (западный форт)
- 32-63: норды (кольцо вокруг форта)
- 64: босс (восток)

Перед запуском нужен террейн: прогони tools/prepare_scenes.py
(копирует terrain.bin/flora.bin/ShaderCache из vanilla-сцены)
или открой сцену в Bannerlord Scene Editor и сохрани.
