# NordInv - Fianna Nord Invasion реализация

Реализация мультиплеерного модуля Nord Invasion для Mount & Blade: Warband в стиле Fianna.ru

## Что это?

Nord Invasion - кооперативный PvE режим:
- Команда игроков (Swadia) обороняет точку от волн ботов-нордов
- Волны усиливаются: 1-3 крестьяне, 4-7 воины, 8+ элита и боссы
- Каждые 4 волны - респавн мертвых игроков
- За убийства дают золото и опыт, на которые покупается снаряжение
- Можно ставить баррикады

Fianna.ru делали упрощенную версию без веб-персистенции - прогресс внутри сессии + локальный банк персонажа.

Этот репозиторий содержит:
1. Готовый скелет Module System для сборки мода
2. Конфиги для выделенного сервера + WSE
3. Документацию как поднять сервер

Смотри `docs/FIANNA_GUIDE_RU.md` - полный гайд.
