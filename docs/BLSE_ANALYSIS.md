# Нужен ли BLSE для Nord Invasion Bannerlord?

## Что такое BLSE

**BLSE (Bannerlord Script Extender)** - аналог SKSE для Skyrim. Нативный DLL который инжектится в процесс Bannerlord и дает доступ к низкоуровневым функциям движка, которые TaleWorlds не открыла в C# API.

**Что дает BLSE:**
- Кастомные сетевые пакеты (для MP)
- Доступ к рендеру, шейдерам, кастомным частицам
- Прямой доступ к файловой системе без ограничений
- Перехват движковых функций которых нет в Harmony
- Возможность грузить нативные плагины на C++

**Что такое Harmony/ButterLib (без BLSE):**
- Harmony патчит C# методы на лету (95% модов используют только это)
- ButterLib - библиотека утилит, UIExtenderEx - для UI
- Этого хватает для MissionBehavior, AgentComponent, DestructibleComponent, Gauntlet UI

## Для Nord Invasion Better Edition - BLSE НЕ обязателен

Все 15 базовых механик делаются без BLSE:

| Механика | Нужен BLSE? | Чем делается |
|----------|-------------|--------------|
| Волны, спавн ботов | Нет | `Mission.SpawnAgent()` |
| Баррикады, колья, котел | Нет | `DestructibleComponent`, `UsableMachine` |
| Роли медик/инженер | Нет | `AgentComponent` |
| Перки, мутаторы, директор | Нет | `MissionBehavior` + Gauntlet UI |
| Погода | Нет | `Mission.Scene.SetRainDensity()`, `SetFog()` |
| Физ-лут мешок | Нет | `UsableMachine` + `AttachProp` |
| Скавенджинг | Нет | `OnAgentRemoved`, `OnDestructibleDestroyed` |
| Отряды с формациями | Нет | Нативный `Formation` API |
| Персистенция | Нет | `HttpClient` в C# |
| Ранения/стамина | Нет | `AgentComponent` |
| Огонь/взрывы | Нет | `ParticleSystem`, `AddExplosion()` |
| Кампания | Нет | `CampaignBehavior` + backend |

**Вывод: 90% мода работает без BLSE.**

## Когда BLSE нужен (для extra механик)

BLSE становится нужен если хочешь:

1. **Кастомный мультиплеер протокол** - если делаешь Dedicated MP с античитом, кастомными пакетами для стройки (обычный MP API Bannerlord очень ограничен). Для Co-op через Bannerlord Co-op - не нужен.

2. **Кастомные шейдеры/рендер** - например, огонь который реально освещает, динамические тени от факелов, кастомный туман. Без BLSE только стандартные шейдеры.

3. **Продвинутая физика** - падающие деревья которые реально ломают баррикады с физикой, а не просто спавн `FallenTree`.

4. **Доступ к файлам вне песочницы** - если хочешь писать логи, реплеи, сейвы куда угодно.

5. **Нативные оптимизации** - если 400 ботов лагают, BLSE может дать доступ к job system.

## Рекомендация

**Фаза 1-4 (MVP): Делай без BLSE.** Используй только Harmony + ButterLib. Так мод будет совместим с 99% игроков, легче ставить, не ломается после каждого патча Bannerlord.

**Фаза 5 (если нужен Dedicated MP с античитом):** Добавь BLSE как опциональную зависимость. В `SubModule.xml`:

```xml
<DependedModule Id="BLSE" DependentVersion="1.0.0" Optional="true"/>
```

В коде проверяй:

```csharp
if (BLSE.IsLoaded) { // используй BLSE фичи }
else { // fallback на обычный API }
```

Так игроки без BLSE смогут играть в Co-op, а сервера с BLSE получат расширенные фичи.

## Итого

- **Для релиза Co-op версии (4-8 игроков): BLSE НЕ нужен.**
- **Для Dedicated MP 32 игрока с кастомной стройкой и античитом: желателен, но не критичен. Можно начать без него, добавить позже.**

Не усложняй на старте. 99% модов Bannerlord (включая Full Invasion) работают без BLSE.
